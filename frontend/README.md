# Cinema Platform — фронтенд

SPA онлайн-кінотеатру: React 19, TypeScript, Vite, React Router, TanStack Query, Tailwind CSS, hls.js, Recharts.
Адмін-частина — розділ `/admin` у цьому ж застосунку.

## Вимоги

- Node.js 20.19+ або 22.12+ (npm входить у комплект)
- Запущений бекенд на `http://localhost:8000` (див. кореневий README)

## Запуск

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Застосунок відкривається на <http://localhost:5173>. Запити до `/api` і `/media` (постери, HLS-плейлисти й сегменти)
dev-сервер проксіює на бекенд `http://localhost:8000`, тому CORS у режимі розробки не потрібен.

Бекенд (база даних — з кореня репозиторію, решта — з каталогу `backend/` в активованому `.venv`):

```bash
docker compose up -d db
cd backend
python -m alembic upgrade head
python -m app.seed --demo
python -m app.tools.demo_media
python -m uvicorn app.main:app --reload
```

`app.tools.demo_media` генерує через ffmpeg демо-відео з назвою тайтлу та рекламний ролик (потрібен ffmpeg у PATH,
займає кілька хвилин). Без нього каталог працює, але кнопка «Дивитись» буде неактивною.

## Змінні середовища

| Змінна | Призначення | За замовчуванням |
|---|---|---|
| `VITE_API_URL` | Базова адреса API. Порожнє значення — запити йдуть на той самий origin (`/api`) через proxy dev-сервера | порожньо |

Якщо фронтенд розгортається окремо від бекенда, вкажіть повну адресу, наприклад `VITE_API_URL=https://api.example.com`.

## Скріншоти для звіту

`scripts/screenshots.ts` (Playwright, Chromium) відкриває застосунок як гість, `demo.user05@example.com`
(Безкоштовний), демо-користувач з Преміумом і адміністратор. Скрипт зберігає 23 PNG у `docs/screenshots/`:
22 знімки 1440×900 і один мобільний знімок каталогу 375×812, усі з `deviceScaleFactor: 2` (файли вдвічі більші за
розміром). Перед кожним знімком він чекає завершення запитів, зникнення спінерів і скелетонів та завантаження
постерів; тости приховано.

Підготовка (один раз):

```bash
cd frontend
npm install
npx playwright install chromium
```

Дані й сервери (з `backend/`, кожен рядок окремо):

```bash
.venv/Scripts/python -m app.seed --demo-activity
.venv/Scripts/python -m app.tools.demo_media
.venv/Scripts/python -m uvicorn app.main:app
```

В іншому терміналі `npm run dev`, у третьому — `npm run screenshots`.

- Облікові дані адміністратора беруться з `backend/.env` (`ADMIN_EMAIL` / `ADMIN_PASSWORD`), без файлу — значення
  за замовчуванням. Користувач з Преміумом — перший демо-користувач з активною підпискою (або `PREMIUM_EMAIL`).

## Авторизація

- Access-токен зберігається лише в памʼяті вкладки, refresh-токен — у `localStorage`.
- Під час старту застосунок відновлює сесію: `POST /api/auth/refresh`, потім `GET /api/users/me`.
- Якщо запит повертає 401, клієнт один раз оновлює токени і повторює запит. Якщо оновити не вдалося,
  сесія завершується і користувача перенаправлено на `/login`.
- Після входу користувач повертається на сторінку, з якої його перенаправили.

## Маршрути

| Маршрут | Що там |
|---|---|
| `/` | гість: заклик увійти і «Популярне»; користувач: «Продовжити перегляд», «Рекомендовано для вас» з поясненням `reason`, «Популярне» |
| `/catalog` | пошук, фільтри (жанри, роки, країна, тип, мін. рейтинг), сортування, пагінація |
| `/titles/:id` | постер, опис, жанри, сезони й епізоди, кнопки «Дивитись» і «У вибране», блок «Схожі» |
| `/watch/:titleId?episode=` | плеєр (лише після входу): реклама для Free, вибір якості, список епізодів |
| `/favorites` | «Вибране» з пагінацією (лише після входу) |
| `/pricing` | заглушка сторінки тарифів |
| `/admin/titles` | таблиця тайтлів з пошуком, створення, редагування, видалення |
| `/admin/titles/:id` | форма тайтлу, постер, сезони й епізоди; завантаження відео фільму або епізоду зі статусом обробки |
| `/admin/genres` | додавання, перейменування і видалення жанрів |
| `/admin` | KPI з `/api/admin/dashboard`, графіки активних користувачів і доходу за 30 днів |
| `/admin/reports?tab=&days=&from=&to=&group=` | звіти «Популярне», «Активність», «Доходи»: графіки, таблиці з тими самими даними, експорт CSV |
| `/admin/settings` | стратегія рекомендацій за замовчуванням, ваги гібриду, вікно популярності, часовий пояс звітів |

Стан фільтрів каталогу зберігається в query-параметрах URL (`?q=…&genre=1&genre=3&kind=movie&sort=year&order=asc&page=2`),
тому посилання з фільтрами можна скопіювати, а кнопки «Назад» / «Вперед» у браузері працюють.
Значення за замовчуванням у URL не пишуться, некоректні параметри ігноруються.

## Перегляд відео

- `GET /api/titles/{id}/playback` повертає план, адресу маніфесту, дані реклами, дозволені якості й позицію відновлення.
  Обмеження плану (Free — до 720p і реклама, Premium — до 1080p без реклами) застосовує бекенд (Playback Proxy),
  фронтенд лише показує те, що отримав.
- hls.js (`hls.js/light`) завантажується разом зі сторінкою `/watch` окремим чанком. Access-токен додається
  заголовком `Authorization` у `xhrSetup` лише для запитів до `/api/`; у Safari з нативним HLS — параметром
  `?access_token=`.
- Пре-рол показується, лише якщо `ads.enabled` і є `preroll_url`. Кнопка «Пропустити» стає активною через 5 с;
  якщо ролик не завантажився, реклама пропускається.
- Прогрес (`PUT /api/history/progress`) надсилається кожні 10 с відтворення, на паузі, при виході зі сторінки
  і при завершенні (`finished: true`).

## Ручна перевірка

1. Запустити бекенд з демо-даними (`python -m app.seed --demo` додає 12 жанрів, 25 фільмів і 6 серіалів
   з сезонами; повторний запуск нічого не дублює) і `npm run dev`.
2. Відкрити <http://localhost:5173/catalog>:
   - ввести частину назви в пошук — через ~0,4 с у URL зʼявиться `q`, сітка оновиться;
   - обрати кілька жанрів, тип «Серіали», роки від/до, країну, мінімальний рейтинг, сортування —
     кожна зміна відображається в URL, сторінка пагінації скидається на першу;
   - оновити сторінку (F5) — фільтри відновлюються з URL; «Скинути фільтри» прибирає все, крім сортування;
   - задати фільтр без результатів — зʼявиться «Нічого не знайдено» з кнопкою скидання;
   - відкрити картку серіалу — на сторінці тайтлу видно список сезонів і епізодів.
3. Увійти як адміністратор (`ADMIN_EMAIL` / `ADMIN_PASSWORD` з `backend/.env`, за замовчуванням
   `admin@example.com` / `admin12345`) і перейти в «Адмінка» → «Фільми та серіали» → «Додати тайтл»:
   - натиснути «Створити» з порожньою формою — під полями зʼявляться помилки;
   - заповнити назву, тип «Серіал», рік, країну, рейтинг, обрати жанри, вибрати файл постера (JPEG/PNG/WebP до 5 МБ) —
     після створення відкриється сторінка редагування з повідомленням «Тайтл створено, постер завантажено»;
   - повторно створити тайтл з тим самим типом, назвою і роком — над формою буде помилка про дублікат (409);
   - спробувати вибрати файл `.txt` або зображення понад 5 МБ — форма покаже помилку, запит не надсилається;
   - на сторінці редагування додати сезон і епізоди, змінити номер сезону, видалити епізод;
   - знайти тайтл у каталозі (`/catalog`) — постер відображається на картці і на сторінці тайтлу.
4. «Жанри»: додати жанр, перейменувати його, спробувати створити дублікат (помилка 409), видалити.
5. У таблиці тайтлів видалити тестовий тайтл через «Видалити» → «Так, видалити».

### Перегляд, вибране, історія

Підготовка: `python -m app.tools.demo_media` (з `backend/`). На чистій БД відео отримують перші 5 фільмів
(«Матриця», «Початок», «Інтерстеллар», «Темний лицар», «Втеча з Шоушенка») і епізоди 1–3 серіалу «Чорнобиль»,
а також створюється реклама `media/ads/preroll`. Кількість змінюється параметрами `--titles`, `--episodes`.

6. Гість на сторінці «Матриці» бачить «▶ Увійти, щоб дивитись». Після входу він повертається на плеєр.
7. Зареєструвати звичайного користувача (план Free) і відкрити «Матрицю» → «▶ Дивитись»:
   - спершу йде реклама з позначкою «Реклама» і таймером; «Пропустити через 5…» стає «Пропустити ›» через 5 с;
   - після реклами стартує фільм; над плеєром «План: Free» і посилання «Преміум: до 1080p без реклами» на `/pricing`;
   - у списку «Якість» є «Авто (…)», 720p, 360p, але немає 1080p; при виборі 360p у DevTools → Network
     запитуються сегменти `360p/seg_*.ts`;
   - у Network запит `master.m3u8` має заголовок `Authorization`, а у відповіді немає рядка `1080p`.
8. Відновлення позиції: подивитись ~25 с і натиснути паузу (у Network зʼявиться `PUT /api/history/progress`),
   перейти на головну. Там зʼявиться рядок «Продовжити перегляд» з карткою «Матриці», смугою прогресу
   і «Зупинились на 0:25 з 0:40». Клік по картці відкриває плеєр з 0:25. Якщо додивитись до кінця, картка зникає.
   Той самий рядок є в профілі.
9. Серіал «Чорнобиль» → «Дивитись»: праворуч список епізодів, поточний підсвічено, під плеєром «Наступний епізод».
   Після завершення епізоду кнопка стає основною. Епізоди 4–5 без відео показують «Відео ще недоступне».
   Фільм без відео (наприклад, шостий у каталозі) має неактивну кнопку «Дивитись» з підказкою «Відео ще не завантажено».
10. Premium: `python -m app.tools.grant_premium <email> --days 30`, оновити сторінку плеєра — реклами немає,
    «План: Premium», у списку якостей зʼявився 1080p.
11. Вибране: натиснути сердечко на картці в каталозі — воно одразу стає золотим; «Вибране» в шапці показує тайтл;
    на сторінці тайтлу кнопка «У вибраному». Повторне натискання прибирає тайтл, на `/favorites` картка зникає одразу.
    Якщо зупинити бекенд і натиснути сердечко, стан повернеться назад. Гостя сердечко веде на вхід.
12. Адмінка, відео: створити тестовий файл
    `ffmpeg -f lavfi -i testsrc2=size=1280x720:duration=20 -f lavfi -i sine=duration=20 -shortest test.mp4`,
    відкрити `/admin/titles/<id фільму>` → секція «Відео» → «Обрати відео» → «Завантажити». Статус змінюється
    «Очікує обробки» → «Обробляється…» → «Готово · 0:20» без оновлення сторінки. Файл `.avi` відхиляється одразу.
    Для серіалу кнопка «Відео» є в рядку кожного епізоду.
13. Помилки: видалити один сегмент у `media/hls/<id>/720p/`, обрати 720p — плеєр покаже «Не вдалося завантажити відео»
    з кнопкою «Спробувати ще раз». Якщо в DevTools → Application видалити `cinema.refresh_token` і оновити `/watch/...`,
    відкриється сторінка входу.

### Рекомендації, звіти, налаштування

Підготовка (з `backend/`): `python -m app.seed --demo-activity` створює 40 користувачів
`demo.user01@example.com` … `demo.user40@example.com` (пароль `demo12345`) з переглядами, Вибраним і платежами
за 90 днів. Сесію адміністратора і демо-користувача зручно тримати в різних вікнах (звичайне й інкогніто),
бо refresh-токен зберігається в `localStorage`.

14. Головна для гостя: блок «Онлайн-кінотеатр» з кнопками «Увійти» і «Зареєструватися» та один рядок «Популярне».
    У DevTools → Network лише `GET /api/recommendations?limit=12&strategy=popularity`. З throttling «Slow 4G»
    під час завантаження видно сірі скелетони карток.
15. Увійти як `demo.user01`: на головній «Продовжити перегляд» (якщо є незавершені перегляди), «Рекомендовано для вас»
    з підписом «Алгоритм: Гібридна» і поясненням під кожною карткою («Бо ви дивились жанр «Драма»», «Схоже на «…»»,
    «Популярне цього тижня»), нижче «Популярне». Тайтлів, які користувач уже починав, у рекомендаціях немає.
    Під `demo.user02` і `demo.user03` (інші улюблені жанри) добірка й пояснення інші. Щойно зареєстрований
    користувач бачить «Алгоритм: Популярне» з порадою, як отримати персональну добірку.
16. Сердечко на картці рекомендації працює так само, як у каталозі. Сторінка тайтлу внизу має блок «Схожі»
    (спільні жанри, близький рік, та сама країна). Якщо зупинити бекенд і оновити головну, у кожному рядку
    з'явиться помилка з кнопкою «Спробувати ще раз»; після запуску бекенда кнопка завантажує дані.
17. Адміністратор → «Огляд» (`/admin`): п'ять KPI (користувачі, активні за 7 днів, активні Premium, дохід за 30 днів,
    тайтли з відео) і два графіки за 30 днів; «Детальніше →» відкриває відповідну вкладку звітів.
18. «Звіти» (`/admin/reports`):
    - «Популярне»: горизонтальні стовпці топ-10 тайтлів і жанрів за глядачами, під кожним графіком таблиця;
      наведення на стовпець показує значення;
    - «7 днів» / «90 днів» змінюють URL (`?days=7`), суми в плитках і графіки; F5 відновлює вибір, «Назад» у
      браузері повертає попередній період; при перемиканні вкладок період зберігається;
    - «Довільний» → «Від» пізніше за «До» → «Застосувати» дає помилку, URL не змінюється; коректні дати
      записуються як `?from=…&to=…`;
    - «Активність»: дві лінії (реєстрації й активні користувачі) з легендою; демо-дані дають перегляди кожного дня;
      період понад 366 днів з групуванням «По днях» повертає «Період задовгий…», «По місяцях» працює;
    - «Доходи»: «По місяцях» групує стовпці доходу (`&group=month`), «Платежі за статусами» показують
      «Оплачено», «Відхилено», «Очікує підтвердження», картка конверсії відповідає плитці «Конверсія free → premium»;
    - «Експорт CSV» завантажує `subscription-revenue_<від>_<до>.csv` (UTF-8 з BOM, роздільник `;`): заголовок
      звіту, період, групування, часовий пояс, підсумок і таблиці, ті самі числа, що на сторінці. Excel відкриває
      файл з кирилицею без перекодування.
19. «Налаштування» (`/admin/settings`):
    - вимкнути всі три слайдери і зберегти — «Хоча б одна вага має бути більшою за 0», запит не надсилається;
      вікно `0` або `400` — «Ціле число від 1 до 365»; пояс `Mars/Base` — «Такого часового поясу немає в базі даних»;
    - стратегія «За улюбленими жанрами» → «Зберегти» → «Налаштування збережено…», під заголовком час зміни.
      У вікні `demo.user01` оновити головну: «Алгоритм: За улюбленими жанрами», пояснення лише
      «Бо ви дивились жанр …» або «Бо у вашому Вибраному є жанр …»;
    - стратегія «Популярне», вікно 30 → пояснення «Популярне за останні 30 днів»;
    - «Гібридна» з вагами 0 / 1 / 0 (лише «Схоже на переглянуте») → більшість пояснень «Схоже на «…»»;
    - пояс `UTC` → у звітах рядок періоду показує «часовий пояс UTC»;
    - наприкінці повернути значення за замовчуванням: «Гібридна», 0.5 / 0.3 / 0.2, 7 днів, `Europe/Kyiv`.
