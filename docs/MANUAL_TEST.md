# Ручна наскрізна перевірка

Чекліст проходиться від чистої бази. Кожен пункт — дія і очікуваний результат. Позначайте `[x]`, а для збою
запишіть у колонку «Примітка» сторінку, кроки й що сталося замість очікуваного.

Дата проходження: ____________ Гілка / коміт: ____________

## 0. Підготовка середовища

Команди з кореня репозиторію (Git Bash або PowerShell, кожен рядок окремо).

```bash
docker compose down -v
docker compose up -d db
cd backend
.venv/Scripts/python -m alembic upgrade head
.venv/Scripts/python -m app.seed --demo-activity
.venv/Scripts/python -m app.tools.demo_media
.venv/Scripts/python -m uvicorn app.main:app --reload
```

В окремому терміналі:

```bash
cd frontend
npm run dev
```

- [ ] `docker compose down -v` прибрав том `pgdata`, тобто база справді порожня.
- [ ] `alembic upgrade head` пройшов без помилок.
- [ ] Сід вивів підсумок: 40 демо-користувачів, історію, Вибране, платежі.
- [ ] `demo_media` згенерував відео для фільмів і епізодів та рекламний ролик (`media/ads/preroll`).
- [ ] <http://localhost:8000/docs> відкривається, <http://localhost:5173> показує головну сторінку.
- [ ] У `.env` стоїть `PAYMENTS_MOCK_ENABLED=true` (інакше сторінка оплати не дасть обрати результат).

Облікові записи:

| Роль | Електронна пошта | Пароль |
|---|---|---|
| Адміністратор | `admin@example.com` (`ADMIN_EMAIL`) | `admin12345` (`ADMIN_PASSWORD`) |
| Демо-користувач | `demo.user01@example.com` … `demo.user40@example.com` | `demo12345` |
| Новий користувач (Безкоштовний) | реєструється в п. 2 | на ваш вибір |

## 4. Оплата Преміуму: три сценарії

Користувач з п. 2. Для кожного сценарію: «Тарифи» → «Оформити Преміум» → сторінка оплати → обрати результат → «Оплатити».

| # | Дія | Очікуваний результат | ✓ | Примітка |
|---|---|---|---|---|
| 4.1 | Результат «Відхилено банком» | Сторінка результату «відхилено», план не змінився. Дзвіночок: «Оплату 99.00 грн за Преміум відхилено. Спробуйте ще раз.» | [ ] | |
| 4.2 | Результат «Очікує підтвердження» | Сторінка «очікує», план не змінився. Сповіщення «…очікує підтвердження банку.» Можна задати відповідь банку з цієї ж сторінки | [ ] | |
| 4.3 | Адмін (інший браузер / інкогніто): «Платежі», фільтр «Очікує», «Підтвердити» | Тост «Платіж №N підтверджено». У користувача після оновлення — Преміум і сповіщення «Підписку Преміум активовано до …» | [ ] | |
| 4.4 | Новий платіж з результатом «Успішна оплата» | Одразу «План Преміум активний до …», чип у шапці «Преміум», термін продовжено ще на 30 днів | [ ] | |

| 4.6 | Дзвіночок: «Позначити все як прочитане» | Лічильник зникає; клік по сповіщенню позначає одне | [ ] | |
